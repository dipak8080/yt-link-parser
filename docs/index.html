yt-link-parser

Get the video ID, link type, start time and playlist from any YouTube link. Free, open source, no dependencies, works in the browser and in Node.

Try a Short, a youtu.be share link or a link with a timestamp.







Install


npm install yt-link-parser


import { parse } from "yt-link-parser";

parse("https://www.youtube.com/shorts/tPEE9ZwTmy0");
// { ok: true, id: "tPEE9ZwTmy0", kind: "short", start: null, ... }



Links it understands




LinkResult


youtube.com/watch?v=ID, m., music.video


youtu.be/ID?si=...video


youtube.com/shorts/IDshort


youtube.com/live/IDlive


youtube.com/embed/IDembed


&t=1m30s, #t=45start time in seconds


youtube.com/playlist?list=...error: playlist


youtube.com.evil.com/...error: invalid





Where it's used


This parser checks every link pasted into YT to MP4, a free YouTube to MP4 converter. It's how the box accepts youtube.com, youtu.be and Shorts links, even with extra text pasted around them. To save a video as an MP4 in up to 1080p, see the YouTube to MP4 1080p guide.
